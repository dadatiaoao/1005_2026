# H743 电机拓展板

基于正点原子阿波罗 V2 STM32H743IIT6 核心板，控制八台串口电机，并连接带电容触摸的 4.3 寸屏幕。

## 引脚分配

下表为后续功能规划；预留接口按实际需要启用。

| 功能 | 引脚 | 配置 / 用途 |
|---|---|---|
| 电机 USART3 | PB10 TX、PB11 RX | 八台电机共用 TTL 总线，地址区分 |
| 预留 USART1 | PA9 TX、PA10 RX | 上位机 / 调试候选 |
| 预留 USART2 | PA2 TX、PA3 RX | 上位机 / 扩展设备候选 |
| 预留 UART4 | PB9 TX、PB8 RX | 上位机 / 扩展设备候选 |
| 预留 UART5 | PC12 TX、PD2 RX | 上位机 / 扩展设备候选 |
| 预留 USART6 | PC6 TX、PC7 RX | 上位机 / 扩展设备候选 |
| LCD 控制 | PD7 CS、PD13 RS、PD5 WR、PD4 RD | FMC：NE1、A18、NWE、NOE |
| LCD D0–D3 | PD14、PD15、PD0、PD1 | 按顺序对应 FMC D0–D3 |
| LCD D4–D12 | PE7–PE15 | 按顺序对应 FMC D4–D12 |

## 电机通信协议

- 使用 USART3 TTL，初始配置 **115200、8N1**；逐台保存地址 **1–8**，`0` 为广播地址。
- 电机设置 `P_Serial=UART_FUN`、`En=Hold`。以下使用 **FW_Emm + 固定 0x6B 校验**；需与实机 `FWType`、`Checksum` 一致，FW_X 的运动参数格式不同。
- 数据以二进制字节发送：`地址 + 功能码 + 命令数据 + 校验码`，不是 ASCII 文本。

常用命令（字节以十六进制表示，`A` 为电机地址）：

| 功能 | 发送格式 |
|---|---|
| 使能 / 失能 | `A F3 AB en 00 6B`，`en=01` 锁轴、`00` 松轴 |
| 速度控制 | `A F6 dir vH vL acc s 6B` |
| 位置控制 | `A FD dir vH vL acc p3 p2 p1 p0 m s 6B` |
| 立即停止 | `A FE 98 00 6B` |
| 读取实时位置 | `A 36 6B` |
| 广播同步启动 | `00 FF 66 6B`，执行各电机已缓存的命令 |

`dir=00/01` 表示 CW/CCW；速度为 16 位 RPM，脉冲数为 32 位，均高字节先发。`acc` 为 0–255 档，0 表示直接启动；`s=00/01` 表示立即执行/缓存待同步。位置模式 `m=00/01/02` 分别为相对上一目标/绝对坐标/相对当前位置。

应答 `A 功能码 02 6B` 表示命令接收正确；`E2` 表示参数或执行条件错误，`EE` 表示格式错误。接收确认不等于运动到位；开启到位回传后，相应动作完成会返回 `9F`。

多机逐台查询并等待应答，命令之间按手册留几毫秒间隔；`Response=None` 仍会回复读参数命令。接收按功能码和帧长解析，不能仅凭 `6B` 分帧。


## 后续使用约定

- 屏幕经 RGB 转 MCU 板接 H1 的 34 针接口，MCU 使用 **16 位 FMC**；LCD 复位接 NRST。转换板须透传四条触摸线。
- 电机不再分配 STEP / DIR / EN。串口 TX / RX 均从 MCU 视角标注；接口 1 针为 RX、2 针为 TX。
- CN3 / CN4 需飞线接入 PC13 / PE3 和 GND；常开 / 常闭确定后再设有效电平与触发边沿。
- 核心板 SDRAM、NAND、QSPI，以及晶振用脚专用保留；其他备用 GPIO 待设备确定后再分配。
- 接入 FreeRTOS 时，建议 TIM6 提供 HAL 时基、SysTick 提供 RTOS 时基；电机串口和 LCD 分别由单一任务管理。
